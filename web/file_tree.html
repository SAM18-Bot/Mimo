Repository guide

Find the source for the Mimo app you use, or open the shared server to follow a request from a route to the database.

Apps and firmware
  • android/ · Android Studio project and Compose screens.
  • desktop/ · Windows tray, tracker and packaging.
  • web/ · Student dashboard, schedule, settings and parent portal.
  • firmware/ · Optional ESP32-CAM Arduino sketch.
Shared server
  • server/main.py · FastAPI entry point and page routes.
  • server/api/ · HTTP routes, authentication and WebSocket events.
  • server/db/ · SQLAlchemy models and Alembic migrations.
  • server/modules/ · Planning, screen tracking, coaching and optional hardware integrations.
  • server/schedulers/ · Background services, reminders and scheduled reports.
Tests, builds and documentation
  • tests/ and scripts/ · Integration tests and verification tools.
  • .github/workflows/ · Continuous integration and app builds.
  • Contributing · Development setup and test commands.
  • docs/ · Client, deployment and historical guides.
